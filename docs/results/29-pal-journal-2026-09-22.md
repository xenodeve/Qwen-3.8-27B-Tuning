## Frozen task

The task was a standalone storage layer around existing `utils/record_store.py`, not CLinkTool wiring:

- new `tools/run_journal.py` and `tests/test_run_journal.py` only;
- `RunJournal(RecordStore)`, `append(run_id, agent_id, result)`, `read(run_id)`;
- one atomic file-per-record `RecordStore.put`, no JSONL/`O_APPEND`/aggregate file;
- length-prefixed collision-proof identity;
- deterministic prefix reads, restart durability, duplicate rejection and corruption propagation;
- tests use `RecordStore(tmp_path)`, never the real home store;
- parent-only hidden oracle covers concurrency, Unicode, identity rejection, corruption isolation, restart, ordering and JSONL regression.
